# ADR 0003 — AOT

- **Estado:** proposto
- **Data:** 2026-11-27

## Contexto

Há o requisito de AOT em todos os projectos onde for possível. O EF Core classifica o suporte a Native AOT como experimental e não suporta queries dinâmicas nesse modo.

## Decisão

Todas as bibliotecas são compatíveis com AOT (`IsAotCompatible`, analisadores de trimming e AOT a falhar o build, JSON por source generators, sem reflexão). Publicam em Native AOT os executáveis onde isso é suportado. Hosts com EF Core correm em JIT com ReadyToRun e modelo compilado enquanto o Native AOT do EF Core for experimental.

## Alternativas consideradas

- **Native AOT em todos os executáveis, incluindo os que usam EF Core:** rejeitada; o suporte é experimental e desaconselhado em produção.
- **Abdicar de AOT:** rejeitada; perde-se o arranque rápido e a disciplina sem reflexão nas bibliotecas.

## Consequências

- Os hosts com EF Core correm em JIT.
- O suporte de Native AOT do EF Core tem de ser reavaliado em cada versão.

## Evidência

Pendente do teste exploratório descrito na Tarefa 8 do plano da fundação. Este ADR passa a `aceite` quando a evidência for registada aqui.
